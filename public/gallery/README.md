# Фотографии галереи Toddlers

Положите сюда реальные фотографии детского сада (`.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`)
и пересоберите сайт (`npm run build`). Они появятся в разделе «Галерея» автоматически,
в порядке имён файлов (например, `01.jpg`, `02.jpg`, …).

Пока папка пуста, на сайте показывается заглушка «Скоро здесь появятся наши фотографии».

Фото для главного экрана: положите файл `main-page.png` в папку `public/` —
он заменит иллюстрацию в Hero.
